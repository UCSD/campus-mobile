# TritonGPT Data Models

This directory contains data models for the TritonGPT chat integration.

## Files

### chat_session.dart
Models for creating and managing chat sessions via `/chat/create-chat-session`.

| Class | Purpose |
|-------|---------|
| `ChatSessionCreationRequest` | Request payload containing `persona_id` (int) |
| `CreateChatSessionID` | Response containing `chat_session_id` |

### chat_response.dart
Models for sending messages and handling streaming responses via `/chat/send-message`.

**Request Models:**
| Class | Purpose |
|-------|---------|
| `RetrievalOptions` | Search options (just `run_search`, defaults to `'always'`) |
| `BasicCreateChatMessageRequest` | Request payload: message, session_id, parent_message_id, etc. |

**Response Models (streaming):**
| Class | Purpose |
|-------|---------|
| `ChatMessageIds` | First line: `user_message_id`, `reserved_assistant_message_id` |
| `ChatCitation` | Citation reference (`citation_num` → `document_id` URL) |
| `ChatStreamChunk` | Stream chunk - mainly `message_delta` (answer text) and `citation_delta` |

### chat_message_persistent.dart
Hive-persisted model for local storage of chat messages.

| Field | Type | HiveField | Description |
|-------|------|-----------|-------------|
| `id` | `String` | 0 | Unique message identifier |
| `text` | `String` | 1 | Message content |
| `authorId` | `String` | 2 | User PID or assistant ID |
| `createdAt` | `int` | 3 | Unix timestamp (ms) |
| `isFromUser` | `bool` | 4 | True if user message |
| `sessionId` | `String?` | 5 | Associated chat session |
| `parentMessageId` | `String?` | 6 | For message threading |

**Hive Configuration:** `typeId: 3`

### chat_history.dart
Models for session index and sidebar display.

| Class | Purpose |
|-------|---------|
| `ChatSessionMeta` | Session index entry (id, title, createdAt, updatedAt) for sidebar |

## API Flow

```
1. Create Session
   POST /chat/create-chat-session
   Body: { "persona_id": <int> }
   Response: { "chat_session_id": "..." }

2. Send Message (streaming)
   POST /chat/send-message
   Body: BasicCreateChatMessageRequest.toJson()
   Response: Line 1 = ChatMessageIds, then stream of ChatStreamChunk
```
