# TritonGPT Data Models

This directory contains data models for the TritonGPT chat integration.

## Files

### chat_session.dart
Models for creating and managing chat sessions via `/chat/create-chat-session`.

| Class | Purpose |
|-------|---------|
| `ChatSessionRequest` | Request payload containing `persona_id` |
| `ChatSession` | Response containing `chat_session_id`, `persona_id`, and `created_at` |

### chat_response.dart
Models for sending messages and handling responses via `/chat/send-message`.

| Class | Purpose |
|-------|---------|
| `ChatMessageRequest` | Request payload with `chat_session_id`, `message`, optional `prompt_id`, and optional `parent_message_id` |
| `ChatResponse` | Response containing `reserved_assistant_message_id` and optional `content`, `is_complete`, `error` |
| `ChatStreamChunk` | Individual streamed JSON chunk from the API response |

**Usage Notes:**
- Omit `parent_message_id` for the first message in a session
- Use `reserved_assistant_message_id` from the response as `parent_message_id` for follow-up messages

### chat_message_persistent.dart
Hive-persisted model for local storage of chat messages.

| Field | Type | HiveField | Description |
|-------|------|-----------|-------------|
| `id` | `String` | 0 | Unique message identifier |
| `text` | `String` | 1 | Message content |
| `authorId` | `String` | 2 | User PID or assistant ID |
| `createdAt` | `int` | 3 | Unix timestamp (ms) |
| `isFromUser` | `bool` | 4 | True if user message |
| `sessionId` | `String?` | 5 | Associated chat session |
| `parentMessageId` | `String?` | 6 | For message threading |

**Hive Configuration:** `typeId: 3`

### chat_history.dart
Models for viewing and managing chat history.

| Class | Purpose |
|-------|---------|
| `ChatHistory` | Full chat session with all messages |
| `ChatHistorySummary` | Lightweight summary for chat list UI |

## API Flow

```
1. Create Session
   POST /chat/create-chat-session
   Body: { "persona_id": "..." }
   Response: { "chat_session_id": "..." }

2. Send First Message
   POST /chat/send-message
   Body: { "chat_session_id": "...", "message": "..." }
   Response: { "reserved_assistant_message_id": "...", stream of content }

3. Send Follow-up Message
   POST /chat/send-message
   Body: { 
     "chat_session_id": "...", 
     "message": "...",
     "parent_message_id": "<reserved_assistant_message_id from step 2>"
   }
```
